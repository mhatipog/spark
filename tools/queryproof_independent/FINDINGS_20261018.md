# QueryProof independent-family generalization — 2026-10-18

## Outcome: negative generalization result, reproduced independently

Both official PySpark versions ran successfully with the previously frozen October 16 historical benchmark, unchanged October 17 ordering and top-k extractors, and a separate configuration-differential comparison.

Successful job: https://github.com/mhatipog/spark/actions/runs/39101882922 . A first run, https://github.com/mhatipog/spark/actions/runs/39101795786 , failed before executing SQL due to a Python module-name collision. Only import priority was corrected; neither SQL nor detector changed.

This is a retrospective independent-family holdout, NOT a newly blind study. The cases were frozen before development of the new Catalyst extractors but had been investigated previously during a structural-ranking study.

For each version: 3 of the 4 independent-family historical bugs reproduced, 0 of 3 detected by automatic QueryProof, 1 of 3 caused result divergence under the differential configurations, 0 of 4 control false accusations. All nine cases across baseline and three alternate settings ran without query-execution errors in both versions: 72 SQL executions total.

This **falsifies broad detection claims**. Ordering and top-k contracts help on order-sensitive issues, but they do not detect wrong row bags, wrong NULL semantics, or wrong subquery scalar values.

Differential comparison is inspired by SQLancer DQP, but **SQLancer itself was not run**. Alternate settings: toggle AQE, disable broadcast or exclude the optimizer rule OptimizeJoinCondition. Only count divergence when results disagree AND the physical plan text changes. A disagreement does not identify which arm is correct.

## Scientific next step

Preserve the baseline permanently. Add an independent, bounded three-valued predicate and subquery semantic checker that interprets a conservative supported subset of Catalyst analyzed expressions on small immutable source fixtures, rather than comparing two optimizer-generated physical plans. This work will be in-sample development on B01/B02/B03, with explicit UNKNOWN outside the subset. Freeze DIFFERENT unseen historical issues for an honest evaluation afterward. Measure false alarms, abstention, independent issue-family recall and source scan/interpretation cost.

Related established methods include SQLancer NoREC, TLP, DQP and CODDTest; claim no original logic and no superiority before direct empirical comparisons. This research branch makes no Apache Spark upstream changes.
